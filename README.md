# Princess Palace

A Princess Day gift page. Open `index.html`.

## Put it on GitHub Pages
1. Create a new repository and upload everything in this folder (keep the files together).
2. Repository Settings, Pages, Source: Deploy from a branch, branch `main`, folder `/ (root)`.
3. Wait a minute. Your link will be `https://<username>.github.io/<repository>/`.

Edit the love notes at the top of the script in `index.html` (the `NOTES` list) and the final letter in the `finale` section.
